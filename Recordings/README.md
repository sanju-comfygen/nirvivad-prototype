# Nirvivad prototype walkthrough

[Watch the captioned walkthrough](Nirvivad_Prototype_Walkthrough_2026-10-06.webm) (68 seconds, 1280×720 WebM, no audio).

The video was captured from the running browser prototype on 6 October 2026 using isolated sample accounts and sample property information. It covers customer mobile entry and role selection, Owner property submission and KYC, Administration property review and information requests, Lawyer approval and restricted case reporting, Buyer enquiry, audit trails, and the Prototype summary page.

[Cover image](Nirvivad_Prototype_Walkthrough_Cover.png)

The recording is a captioned sequence of live prototype screens. It contains no real customer records. Browser-local demo data used for the recording was kept in an isolated temporary Chrome profile and did not change the team's browser data.
